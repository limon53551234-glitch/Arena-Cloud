1

📤 Как отправить посылку другу?

1. Создай .acloud во вкладке «Создать» и скачай его.
2. Перешли другу два файла: этот сайт (страничку) + твой .acloud — например в Telegram или WhatsApp.
3. Друг открывает сайт → «Открыть» → выбирает твой файл. Готово! 🎉

⏳ Помни про срок жизни: друг должен успеть открыть посылку вовремя!

✍️ Расписка — после открытия посылки нажми «Ответить распиской», получишь зашифрованную строку. Отправитель вставит её во вкладке «Текст» и увидит красивое подтверждение «✅ твою посылку получили».
🔤 Файлы не нужны? Во вкладке «Текст» напиши сообщение — получишь строку ACTXT1:… Её можно отправить просто сообщением в любом мессенджере, а друг расшифрует её там же, во вкладке «Текст».
🌐 Общий реестр в GitHub

Никакого сервера: страница сама читает и правит файл arena-users.json прямо в твоём репозитории через GitHub API. Впиши репозиторий и токен — и по одному ID можно будет войти с любого устройства.

Токен хранится только в этом браузере и никуда не уходит, кроме api.github.com. Создаётся в GitHub → Settings → Developer settings → Fine-grained tokens.
