👋 Привет! Давай создадим аккаунт

Придумай имя — а мы выдадим тебе уникальный 12-значный ID. Он будет автоматически подписывать все твои посылки.

Телефон нужен, чтобы подтвердить, что аккаунт настоящий. Для гостевого аккаунта он не требуется.
Пароль нужен, чтобы никто не вошёл по твоему ID

Гостевому аккаунту не нужны ни телефон, ни документы — но он помечается как гостевой в каждой посылке и его нельзя передать другому человеку.

У меня уже есть ID — войти 🪪
Шестизначный код из профиля «🛡️ Защита входа» — он меняется каждые 30 секунд.

🛡️ Защита входа

Второй фактор после пароля: при входе приложение спросит шестизначный код, который меняется каждые 30 секунд. Отметка о защите уходит в общий реестр, поэтому на чужом устройстве без кода не пустит — там поможет одноразовый код восстановления.

------
30
Код действует 30 секунд и меняется сам. Никому его не диктуй — даже тому, кто представляется поддержкой.
🔑 Передать аккаунт

Отдаёшь аккаунт другому человеку: укажи его ID и придумай новый пароль. В следующую посылку ляжет файл _ПЕРЕДАЧА_АККАУНТА.txt — получатель откроет её и заберёт аккаунт себе. Передача одноразовая: после упаковки посылки она снимается.

📤 Как отправить посылку другу?

1. Создай .acloud во вкладке «Создать» и скачай его.
2. Перешли другу два файла: этот сайт (страничку) + твой .acloud — например в Telegram или WhatsApp.
3. Друг открывает сайт → «Открыть» → выбирает твой файл. Готово! 🎉

⏳ Помни про срок жизни: друг должен успеть открыть посылку вовремя!

✍️ Расписка — после открытия посылки нажми «Ответить распиской», получишь зашифрованную строку. Отправитель вставит её во вкладке «Текст» и увидит красивое подтверждение «✅ твою посылку получили».
🔤 Файлы не нужны? Во вкладке «Текст» напиши сообщение — получишь строку ACTXT1:… Её можно отправить просто сообщением в любом мессенджере, а друг расшифрует её там же, во вкладке «Текст».
🌐 Общий реестр в GitHub

Никакого сервера: страница сама читает и правит файл arena-users.json прямо в твоём репозитории через GitHub API. Впиши репозиторий и токен — и по одному ID можно будет войти с любого устройства.

Токен хранится только в этом браузере и никуда не уходит, кроме api.github.com. Создаётся в GitHub → Settings → Developer settings → Fine-grained tokens.

Подключение общее для всех: один реестр — один аккаунт на все устройства. Список зарегистрированных показывается только администратору.

Общая стена для всех, кто подключён к одному реестру. Работает по тому же принципу, что и аккаунты: сервера нет — записи лежат прямо в файле arena-users.json в репозитории, страница сама их читает и сама коммитит новые. Поэтому ленту видят все, кто подключил этот же репозиторий.
